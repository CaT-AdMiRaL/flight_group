# ИУС лётной группы авиакомпании

Проект по дисциплине «Информационно-управляющие системы».

**Тема:** Проектирование ИУС планирования и контроля выполнения мероприятий производственной программы лётной группы авиакомпании.

## О проекте

Система нужна для составления плана мероприятий лётной группы и контроля его выполнения. Она позволяет сравнивать плановые и фактические данные, находить отклонения и формировать отчёты.

В работе рассмотрены два процесса:
- **BP-01** — планирование мероприятий;
- **BP-02** — контроль выполнения плана.

Также предусмотрен ИИ-компонент, который предлагает варианты действий при отклонениях. Решение принимает пилот-инструктор лётной группы (ПИЛГ).

## Файлы проекта

- `constitution.md` — основные принципы проекта;
- `docs/report.docx` — отчёт по первому этапу;
- `docs/diagrams/` — диаграммы BP-01 и BP-02;
- `docs/traceability.md` — матрица трассируемости;
- `sdd/spec.md` — требования к системе;
- `sdd/plan.md` — план разработки;
- `sdd/tasks.md` — список задач.

## Первый этап

Подготовлены диаграммы процессов, требования к системе, KPI, описание ИИ-компонента и документы для дальнейшей разработки.
