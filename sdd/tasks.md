# Задачи по разработке ИУС лётной группы

## 1. Подготовка

- [ ] Создать проект веб-приложения и базу данных.
- [ ] Добавить роли пользователей: подразделение авиакомпании и ПИЛГ.

## 2. Планирование (BP-01)

- [ ] Сделать ввод плановых данных о рейсовой работе, безопасности полётов и подготовке пилотов.
- [ ] Добавить проверку заполнения и корректности данных.
- [ ] Реализовать формирование сводного плана, его утверждение ПИЛГ и возврат на доработку.

## 3. Контроль (BP-02)

- [ ] Сделать ввод фактических данных и их проверку.
- [ ] Реализовать сравнение плана с фактом и регистрацию отклонений.
- [ ] Добавить просмотр отклонений, сохранение решений ПИЛГ и формирование отчёта.

## 4. ИИ-компонент

- [ ] Подключить ИИ для анализа зарегистрированных отклонений и подготовки рекомендаций.
- [ ] Сделать инструменты MCP для получения плана, фактических данных и списка отклонений (на первом этапе допустимы заглушки).
- [ ] Показывать ПИЛГ рекомендации и их обоснование, не применять их автоматически.
- [ ] Предусмотреть работу контроля и отчётности без ИИ.

## 5. Проверка

- [ ] Проверить оба процесса на учебных данных, включая ошибки ввода и отсутствие отклонений.
- [ ] Проверить, что решения сохраняются, а ИИ не меняет утверждённые данные.
- [ ] Проверить вызовы MCP-инструментов и записать результаты тестирования.
