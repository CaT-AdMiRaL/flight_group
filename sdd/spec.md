# Спецификация ИУС лётной группы

## 1. Для чего нужна система

ИУС нужна для подготовки плана производственной программы лётной группы и проверки его выполнения. Система работает с данными о рейсовой работе, мероприятиях по безопасности полётов и подготовке пилотов.

## 2. Кто работает с системой

- **Подразделения авиакомпании** передают плановые и фактические данные, исправляют ошибки.
- **ПИЛГ** проверяет план, принимает решения по отклонениям и рассматривает рекомендации.

## 3. Что должна делать система

**Планирование (BP-01):**
- собирать и проверять исходные данные;
- составлять общий план на выбранный период;
- показывать ошибки и несоответствия;
- передавать план ПИЛГ на рассмотрение;
- сохранять принятый план и его изменения.

**Контроль (BP-02):**
- получать и проверять фактические данные;
- сравнивать их с планом и отмечать отклонения;
- предлагать рекомендации с помощью ИИ;
- сохранять решения ПИЛГ;
- формировать итоговый отчёт.

## 4. Ограничения и проверка результата

ИИ только предлагает решения и кратко объясняет их. Если данных недостаточно, он должен об этом сообщить. При отключении ИИ сравнение показателей и отчёты продолжают работать.

ИУС не составляет расписание рейсов, не назначает экипажи и не управляет полётами.

Работа считается выполненной, если можно создать и принять план, внести фактические данные, увидеть отклонения, получить рекомендации и итоговый отчёт. Все решения ПИЛГ должны сохраняться.
