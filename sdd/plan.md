# План разработки ИУС лётной группы

## 1. Общая идея

Планируется веб-приложение для планирования и контроля производственной программы лётной группы. Подразделения авиакомпании вносят данные, ПИЛГ проверяет планы и принимает решения. ИУС сравнивает план с фактом и составляет отчёты.

## 2. Основные части системы

- **Интерфейс** — ввод данных, просмотр планов и отчётов.
- **Модуль планирования** — проверка данных и подготовка сводного плана.
- **Модуль контроля** — сравнение плановых и фактических показателей, учёт отклонений.
- **ИИ-компонент** — рекомендации по выявленным отклонениям.
- **База данных** — планы, мероприятия, показатели, отклонения и решения ПИЛГ.

## 3. Как будет работать система

**BP-01. Планирование**

1. Подразделения передают плановые данные.
2. ИУС проверяет их и формирует проект плана.
3. ПИЛГ утверждает план или возвращает его на доработку.

**BP-02. Контроль**

1. Подразделения предоставляют фактические данные.
2. ИУС проверяет данные и сравнивает их с утверждённым планом.
3. При отклонениях ИИ предлагает корректирующие действия.
4. ПИЛГ принимает решение, ИУС фиксирует его и формирует отчёт.

## 4. Проверка

Работу системы проверим на учебных данных: создание и утверждение плана, обработка ошибок, выявление отклонений, рекомендации ИИ и формирование отчёта. Если ИИ недоступен, проверка показателей и отчётность должны продолжать работать.
